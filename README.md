# Python Bioinformatics Basics

##  Project Description
This repository contains my 2-week learning journey in Python, focused on building foundational skills in bioinformatics and data analysis.  

The project covers basic Python programming concepts and applies them to biological data such as DNA sequences and gene analysis.

##  Week 1 Topics
- Variables (int, float, string, boolean)
- Strings and string methods
- Lists
- For loops
- Dictionaries

##  Week 2 Topics
- Conditions (if/else statements)
- File handling
- Error handling (try/except)
- Modules
- Jupyter Notebook practice


##  Example Bioinformatics Concepts Covered
- DNA sequence representation
- Gene names handling
- Sequence length calculation
- GC content (GC ratio) calculation

##  Project Goal
To build a strong foundation in Python programming for bioinformatics, data handling, and future data science applications.
